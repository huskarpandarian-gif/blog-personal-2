# Blog personal PHP

## Estructura
- `api/index.php`: plantilla principal, navegación y enrutamiento por `?seccion=`.
- `api/secciones/`: cuatro páginas internas: Sobre mí, Estudios, Experiencia y Contacto.
- `assets/foto-perfil.jpg`: coloca aquí tu fotografía.
- `vercel.json`: configuración de despliegue en Vercel con runtime PHP comunitario.

## Personalización
1. En `api/index.php`, cambia `Tu nombre aquí` por tu nombre.
2. Reemplaza `assets/foto-perfil.jpg` por tu foto (mantén ese nombre).
3. Edita los archivos dentro de `api/secciones/` para completar carrera, fechas, logros, correo y enlaces.
4. Ajusta la descripción y los datos de contacto antes de publicar.

## Despliegue
Sube la carpeta del proyecto a GitHub e impórtala en Vercel. El runtime PHP indicado es comunitario; comprueba su compatibilidad y disponibilidad antes de desplegar.
